# dc_lf 技术文档

## 模块定位

`src/hybrid_power_system_analysis/lfcore/dc_lf.py` 实现直流电网 Newton 潮流计算。核心类是 `DCPowerFlowCalc`。

该模块负责：

- 分析直流网络拓扑和存活设备。
- 构造直流电导矩阵和零阻抗支路约束。
- 支持直流电源、负荷、普通电阻支路、零阻抗支路、开关、DC/DC 变流器。
- 对全直流网络建立统一残差和稀疏 Jacobian。
- 收敛后回填节点电压、支路电流、功率、负荷和电源出力。

## 入口与使用方式

```python
from lfcore.dc_lf import DCPowerFlowCalc

calc = DCPowerFlowCalc(network, tol=1e-8, max_iter=50, min_voltage=0.01, verbose=False)
rc = calc.run()
```

`run()` 内部会在需要时自动调用 `prepare()`；外部只有在需要调试或复用中间矩阵时才需要单独调用 `prepare()`。

## 支持的模型对象

| 对象 | 作用 |
| --- | --- |
| `DCNode` | 直流节点，含电压基准和初始电压 |
| `DCBranch` | 普通电阻支路，参数 `r` |
| `DCZeroBranch` | 零阻抗支路，作为等电位约束处理 |
| `DCSwitch` | 直流开关，闭合时作为零阻抗边 |
| `DCLoad` | 直流 ZIP 负荷，`pv0/pv1/pv2` |
| `DCGenerator` | 直流电源，支持 `V/P/I` 控制 |
| `DCDCConverter` | DC/DC 变流器，采用 `r1 + 理想变比 + r2` 模型 |

所有设备均受 `run_stat` 控制；开关还受状态字段控制。

## 状态变量

直流潮流状态主要包括：

| 变量 | 含义 |
| --- | --- |
| `V` | 存活直流节点电压 |
| `phi` | 零阻抗支路辅助势变量 |
| `DCDC P_FROM/P_TO` | DC/DC 变流器两端功率状态 |

定电压源或定电压变流器提供参考电压。普通节点电压由方程求解。

## 方程模型

### 普通电阻支路

普通支路按欧姆定律：

```text
I_ij = (V_i - V_j) / r
P_i = V_i * I_ij
P_j = -V_j * I_ij
```

### 负荷模型

直流负荷为电压相关 ZIP 形式：

```text
P_load(V) = pv0 + pv1 * V + pv2 * V^2
```

### 电源控制

`DCGenerator` 支持：

| 控制 | 方程含义 |
| --- | --- |
| `V` | 电压固定，电源功率作为平衡结果回填 |
| `P` | 有功固定 |
| `I` | 电流固定，有功随电压变化 |

### DC/DC 变流器

当前 DC/DC 模型为 `r1 + 理想变压 + r2`。两端功率和电流由变流器功率状态与节点电压关系确定，损耗由两侧电阻消耗体现。

## 残差与 Jacobian

`get_f(x)` 计算：

- 节点功率平衡。
- 定电压节点约束。
- 零阻抗支路等电位约束。
- DC/DC 控制方程和损耗方程。

`get_jacobi(G, x)` 生成稀疏 Jacobian。普通支路电导矩阵 `G` 在 `prepare()` 阶段建立，零阻抗和变流器相关导数按数组直接写入稀疏矩阵。

## 求解流程

`run()` 流程：

1. 读取 `lf.para` 并合并运行时覆盖参数。
2. `prepare()` 建立拓扑、变量索引、初始状态和电导矩阵。
3. Newton 迭代计算 `F`。
4. 若 `||F||_inf < tol`，回填结果并返回 `0`。
5. 若残差超过 `divergence_threshold`，停止并返回 `-1`。
6. 用 `spsolve(J, -F)` 求修正量；失败时退化为稠密最小二乘。

## 结果回填

`update_lf_info(x)` 更新：

- 节点电压。
- 普通支路电流、两端功率。
- 零阻抗支路和开关电流/功率。
- 负荷功率和电流。
- DC/DC 变流器两端功率和电流。
- 定电压源承担的平衡功率。

## 性能设计

- 拓扑和设备索引在 `prepare()` 阶段一次性建立。
- 支路和负荷计算使用 NumPy 数组批量操作。
- Jacobian 使用稀疏矩阵直接构造。
- 对大型直流算例，主要耗时集中在稀疏线性方程求解。

## 注意事项

- 每个存活直流岛必须至少有一个电压控制源。
- 多个定电压源位于同一岛时需要确认拓扑和控制设定合理。
- 零阻抗支路不应以极小电阻普通支路替代。
