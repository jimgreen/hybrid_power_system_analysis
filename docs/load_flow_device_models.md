# 潮流计算设备模型、参数、状态及约束

本文档基于 `src/hybrid_power_system_analysis/lfcore/ac_lf.py`、`dc_lf.py`、`hybrid_lf.py` 及其数组模型整理，说明潮流计算中参与建模的典型电网设备。所有数值默认采用标幺值；`run_stat=1` 表示设备投入运行，`status=1` 表示开关类设备闭合。

## 1. 求解范围

潮流计算分为三条路径：

- AC 潮流：`ACPowerFlowCalc`，使用极坐标 Newton-Raphson。状态变量包含节点相角 `theta`、电压幅值 `V`，以及零阻抗支路辅助电位 `phi_re/phi_im`。
- DC 潮流：`DCPowerFlowCalc`，使用节点电压 Newton 求解。状态变量包含节点电压 `V`、零阻抗辅助电位 `phi`，以及 DC-DC 变流器两端端口功率。
- 交直流联合潮流：`HybridPowerFlowCalc`，把 AC 子系统、DC 子系统、DC/AC 变流器和 AC/AC 变流器拼接到同一个全局 Newton 方程组中。

## 2. 公共拓扑状态

| 字段 | 含义 | 参与方式 |
| --- | --- | --- |
| `idx` | 设备或节点编号 | 作为 E 文件和数组模型中的主键 |
| `name` | 设备名称 | 用于结果输出和文档定位，不参与方程 |
| `run_stat` | 运行状态 | `0` 的设备不参与拓扑和方程 |
| `status` | 开关/刀闸闭合状态 | `1` 才按闭合支路处理 |
| `isl` | 拓扑岛编号 | 用于过滤无平衡源岛 |
| `is_alive` | 设备是否在可计算岛内 | 由拓扑预处理得到 |

AC 和 DC 求解都会先剔除停运设备、断开开关以及无有效平衡源的拓扑岛。闭合开关在拓扑上可合并节点或作为零阻抗约束参与计算，具体取决于 AC/DC 求解器路径。

## 3. AC 设备模型

### 3.1 ACNode / ACBus

典型参数：

| 参数 | 含义 |
| --- | --- |
| `idx` | 节点编号 |
| `vbase` | 电压基值 |
| `voltage` | 电压幅值初值或结果 |
| `angle` | 电压相角初值或结果 |
| `run_stat` | 节点运行状态 |

状态变量：

- PQ 节点：`theta`、`V` 均为未知量。
- PV 节点：`theta` 为未知量，`V` 由发电机或电压源约束给定。
- Slack 节点：`theta` 和 `V` 均给定，承担全网功率不平衡。

约束：

- PQ 节点使用有功、无功功率平衡。
- PV 节点使用有功功率平衡和电压幅值约束。
- Slack 节点使用电压幅值和相角约束。

### 3.2 ACBranch

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端 AC 节点 |
| `r`, `x` | 串联电阻、电抗 |
| `b` | 线路对地电纳，按两端各一半处理 |
| `run_stat` | 运行状态 |

计算模型：

- 支路导纳为 `1 / (r + jx)`。
- 对地电纳采用 `j*b/2` 加到两端自导纳。
- 支路功率由两端复电压和支路电流计算。

结果状态：

| 状态 | 含义 |
| --- | --- |
| `i_p`, `i_q`, `i_c` | i 端有功、无功、电流 |
| `j_p`, `j_q`, `j_c` | j 端有功、无功、电流 |

约束：

- 支路本身不新增独立方程，而是通过 Y 矩阵进入节点 P/Q 平衡。
- 两端电压基值应一致，否则拓扑检查会报错。

### 3.3 ACTransformer

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端节点 |
| `r`, `x`, `b` | 等值阻抗和励磁/对地电纳 |
| `tap` | 变比幅值，缺省为 `1.0` |
| `shift` | 移相角，单位为度 |
| `run_stat` | 运行状态 |

计算模型：

- 使用 MATPOWER 风格支路导纳印章：`Yff`、`Yft`、`Ytf`、`Ytt`。
- `tap` 和 `shift` 作用在 i 侧等值变比上。

结果状态与 ACBranch 相同，包括两端 P/Q/I。

约束：

- 通过 Y 矩阵进入节点平衡。
- 不单独引入控制方程；变比和移相角在一次潮流中作为给定参数。

### 3.4 ACGenerator

典型参数：

| 参数 | 含义 |
| --- | --- |
| `node` | 接入节点 |
| `control_type` | 控制类型 |
| `p_set`, `q_set` | 有功、无功设定 |
| `v_set` | 电压设定 |
| `alpha` | 多机分担系数 |
| `run_stat` | 运行状态 |

典型控制：

| 控制类型 | 节点类型 | 约束 |
| --- | --- | --- |
| `PQ` | PQ | 给定 `P/Q` 注入 |
| `PV` | PV | 给定 `P` 和节点电压 `V` |
| `V` / `SLACK` / `PH` | Slack | 给定节点电压与相角，承担不平衡功率 |

结果状态：

- `p`、`q` 为潮流回填后的出力。
- `current` 由 `sqrt(p^2 + q^2) / V` 得到。

约束：

- 同一可计算岛通常需要一个平衡电源。
- 多个平衡源只有在零阻抗等值相连且电压设定一致时可被视作同一理想母线，否则拓扑检查会报错或告警。

### 3.5 ACLoad

典型参数：

| 参数 | 含义 |
| --- | --- |
| `node` | 接入节点 |
| `pbase`, `qbase` | 有功、无功基准 |
| `pv0`, `pv1`, `pv2` | 有功 ZIP 系数 |
| `qv0`, `qv1`, `qv2` | 无功 ZIP 系数 |
| `run_stat` | 运行状态 |

计算模型：

```text
P_load(V) = pbase * (pv0 + pv1 * V + pv2 * V^2)
Q_load(V) = qbase * (qv0 + qv1 * V + qv2 * V^2)
```

结果状态：

- `p`、`q` 为实际消耗功率。
- `current` 由 `sqrt(p^2 + q^2) / V` 得到。

约束：

- 负荷作为节点注入的负项进入 P/Q 平衡。
- ZIP 负荷对电压的偏导进入 Jacobian。

### 3.6 ACShuntCompensator

典型参数：

| 参数 | 含义 |
| --- | --- |
| `node` | 接入节点 |
| `control_type` | `Q`、`B`、`Z`、`V` 等控制类型 |
| `q_set` | 定无功注入 |
| `g_set`, `b_set` | 并联电导、电纳 |
| `v_set` | 电压设定 |

计算模型：

- `B/Z` 或存在 `g_set` 时按并联导纳处理：`P = V^2 * g_set`，`Q = -V^2 * b_set`。
- `Q` 控制按固定无功注入处理。
- `V` 控制用于电压约束语义，实际参与方式由节点类型和设备预处理决定。

约束：

- 并联导纳进入节点导纳矩阵。
- 定无功或定电压控制进入节点功率/电压约束。

### 3.7 ACZeroBranch / ACSwitch / ACBreak

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端节点 |
| `status` | 开关/刀闸闭合状态 |
| `run_stat` | 运行状态 |

计算模型：

- 零阻抗支路不使用小电阻近似。
- 每个零阻抗连通分量引入辅助电位 `phi`。
- 支路电流由 `I_ij = phi_i - phi_j` 表示。

约束：

- 连通分量生成树上的支路增加 `V_i = V_j` 约束。
- 每个零阻抗连通分量固定一个 `phi = 0`，消除平移自由度。
- 闭合开关和闭合刀闸按零阻抗约束处理；断开设备不参与方程。

结果状态：

- `p`、`q`、`current` 表示从 i 端流出的功率和电流。

## 4. DC 设备模型

### 4.1 DCNode / DCBus

典型参数：

| 参数 | 含义 |
| --- | --- |
| `idx` | 节点编号 |
| `vbase` | 电压基值 |
| `voltage` | 电压初值或结果 |
| `run_stat` | 运行状态 |

状态变量：

- 普通节点电压 `V` 为未知量。
- 定压节点由 DC 发电机或 DCDC 定压控制提供电压约束。

约束：

- 非定压节点使用有功功率平衡。
- 定压节点使用 `V = v_set`。

### 4.2 DCBranch

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端 DC 节点 |
| `r` | 电阻 |
| `run_stat` | 运行状态 |

计算模型：

```text
I_ij = (V_i - V_j) / r
P_i = V_i * I_ij
P_j = -V_j * I_ij
loss = P_i + P_j
```

约束：

- 支路电导进入节点功率平衡。
- 支路两端节点必须位于可计算拓扑岛内。

结果状态：

- `i_p`、`j_p`、`current`。

### 4.3 DCGenerator

典型参数：

| 参数 | 含义 |
| --- | --- |
| `node` | 接入节点 |
| `control_type` | `P`、`V`、`I` |
| `p_set` | 定功率设定 |
| `v_set` | 定电压设定 |
| `i_set` | 定电流设定 |

控制模型：

| 控制类型 | 模型 |
| --- | --- |
| `P` | `P = p_set` |
| `V` | `V = v_set`，作为平衡/定压源 |
| `I` | `P = i_set * V` |

结果状态：

- `p` 为出力功率。
- `current = p / V`。

### 4.4 DCLoad

典型参数：

| 参数 | 含义 |
| --- | --- |
| `node` | 接入节点 |
| `pbase` | 有功基准 |
| `pv0`, `pv1`, `pv2` | 电压相关负荷系数 |

计算模型：

```text
P_load(V) = pbase * (pv0 + pv1 * V + pv2 * V^2)
I_load = P_load / V
```

约束：

- 作为负荷项进入节点有功平衡。
- 对电压的导数进入 Jacobian。

### 4.5 DCZeroBranch / DCSwitch / DCBreak

模型与 AC 零阻抗支路类似，但只处理实数电压和实数电流：

- 每个零阻抗连通分量引入 `phi`。
- 支路电流为 `I_ij = phi_i - phi_j`。
- 生成树上增加 `V_i = V_j` 约束。
- 每个连通分量固定一个 `phi = 0`。

结果状态：

- `p` 表示 i 端功率。
- `current` 表示支路电流。

### 4.6 DCDCConverter

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端 DC 节点 |
| `r1`, `r2` | 两端等效损耗电阻 |
| `control_type` | `P`、`V`、`I` |
| `p_set` | 定功率设定 |
| `v_set` | 定电压设定 |
| `i_set` | 定电流设定 |

状态变量：

- 每台 DCDC 引入两个端口功率未知量：`P_i`、`P_j`。

约束：

| 方程 | 含义 |
| --- | --- |
| i 端节点功率平衡 | 把 `P_i` 加入 i 端节点 |
| j 端节点功率平衡 | 把 `P_j` 加入 j 端节点 |
| 损耗方程 | 两端端口功率与 `r1/r2` 损耗一致 |
| 控制方程 | 按 `P`、`V` 或 `I` 控制模式给定一个端口条件 |

结果状态：

- `i_p`、`j_p` 为两端功率。
- `i_c`、`j_c` 为两端电流。

## 5. 交直流联合设备模型

### 5.1 DCACConverter

典型参数：

| 参数 | 含义 |
| --- | --- |
| `dc_node` | DC 侧节点 |
| `ac_node` | AC 侧节点 |
| `r1`, `r2` | DC 侧与 AC 侧等效损耗电阻 |
| `control_type` | `DCV`、`ACV`、`ACP` |
| `p_ac_set` | AC 侧有功设定 |
| `q_ac_set` | AC 侧无功设定 |
| `v_ac_set` | AC 侧电压设定 |
| `v_dc_set` | DC 侧电压设定 |

状态变量：

- 每台 DCAC 引入三个未知量：`Pdc`、`Pac`、`Qac`。

约束：

| 方程 | 含义 |
| --- | --- |
| AC P 平衡耦合 | `Pac` 加入 AC 节点有功残差 |
| AC Q 平衡耦合 | `Qac` 加入 AC 节点无功残差 |
| DC P 平衡耦合 | `Pdc` 加入 DC 节点有功残差 |
| 损耗方程 | `Pdc + Pac` 与两侧等效电阻损耗一致 |
| 无功设定 | `Qac = q_ac_set` |
| 控制方程 | `DCV` 给定 DC 电压，`ACV` 给定 AC 电压，`ACP` 给定 AC 有功 |

约束限制：

- AC 侧节点必须是 PQ 节点，否则会与 AC PV/Slack 约束冲突。
- DC 和 AC 两侧节点必须都在可计算拓扑岛内。

结果状态：

- `dc_p`、`ac_p`、`ac_q`。
- `dc_i = dc_p / Vdc`。
- `ac_i = sqrt(ac_p^2 + ac_q^2) / Vac`。

### 5.2 ACACConverter

典型参数：

| 参数 | 含义 |
| --- | --- |
| `i_node`, `j_node` | 两端 AC 节点 |
| `r1`, `r2` | 两端等效损耗电阻 |
| `control_type` | `PQQ`、`PVQ`、`PQV`、`PVV` |
| `p_set` | i 侧有功设定 |
| `i_q_set`, `j_q_set` | i/j 侧无功设定 |
| `i_v_set`, `j_v_set` | i/j 侧电压设定 |

状态变量：

- 每台 ACAC 引入四个未知量：`Pi`、`Qi`、`Pj`、`Qj`。

约束：

| 方程 | 含义 |
| --- | --- |
| i 侧 P/Q 平衡耦合 | `Pi/Qi` 加入 i 侧 AC 节点残差 |
| j 侧 P/Q 平衡耦合 | `Pj/Qj` 加入 j 侧 AC 节点残差 |
| 损耗方程 | `Pi + Pj` 与两侧等效电阻损耗一致 |
| 有功控制 | `Pi = p_set` |
| i 侧控制 | `PQQ/PQV` 给定 `Qi`，`PVQ/PVV` 给定 `Vi` |
| j 侧控制 | `PQQ/PVQ` 给定 `Qj`，`PQV/PVV` 给定 `Vj` |

约束限制：

- 两端 AC 节点都必须是 PQ 节点。
- 两端不能连接同一个 AC 节点。
- 两端节点必须在可计算拓扑岛内。

结果状态：

- `i_p`、`i_q`、`j_p`、`j_q`。
- `i_i = sqrt(i_p^2 + i_q^2) / Vi`。
- `j_i = sqrt(j_p^2 + j_q^2) / Vj`。

## 6. 方程和变量总览

### 6.1 AC 潮流

```text
x_ac = [theta_unknown, V_unknown, phi_re, phi_im]
```

方程包括：

- 非 Slack 节点有功平衡。
- PQ 节点无功平衡。
- PV/Slack 节点电压约束。
- Slack 节点相角约束。
- 零阻抗生成树电压相等约束。
- 每个零阻抗连通分量的 phi 参考约束。

### 6.2 DC 潮流

```text
x_dc = [V, phi, Pdc_i, Pdc_j]
```

方程包括：

- 普通节点有功平衡。
- 定压节点电压约束。
- 零阻抗生成树电压相等约束。
- 每个零阻抗连通分量的 phi 参考约束。
- DCDC 控制方程和损耗方程。

### 6.3 交直流联合潮流

```text
x_hybrid = [x_ac, x_dc, dcac(Pdc, Pac, Qac), acac(Pi, Qi, Pj, Qj)]
```

方程包括：

- AC 子系统原有方程。
- DC 子系统原有方程。
- DCAC 对 AC/DC 节点功率平衡的耦合项。
- DCAC 损耗、无功和控制约束。
- ACAC 对两端 AC 节点功率平衡的耦合项。
- ACAC 损耗、有功和 Q/V 控制约束。

## 7. 结果回填字段

潮流收敛后，求解器会把结果写回模型对象或数组 `ppc`：

| 设备 | 回填字段 |
| --- | --- |
| AC/DC 节点 | `voltage`，AC 还包括 `angle` |
| AC 支路/变压器 | `i_p`、`i_q`、`i_c`、`j_p`、`j_q`、`j_c` |
| DC 支路 | `i_p`、`j_p`、`current` |
| 负荷 | `p`、AC `q`、`current` |
| 发电机 | `p`、AC `q`、`current` |
| 并联补偿 | `p`、`q`、`current` |
| 零阻抗支路/开关/刀闸 | `p`、AC `q`、`current` |
| DCDC | `i_p`、`j_p`、`i_c`、`j_c` |
| DCAC | `dc_p`、`ac_p`、`ac_q`、`dc_i`、`ac_i` |
| ACAC | `i_p`、`i_q`、`j_p`、`j_q`、`i_i`、`j_i` |

## 8. 建模注意事项

- 所有参与潮流的拓扑岛必须至少有一个有效定压源或平衡源。
- 零阻抗支路、闭合开关和闭合刀闸不应通过小阻抗近似处理；当前代码使用 phi 辅助变量精确建模。
- AC 支路和开关类设备两端电压基值应一致。
- DCAC 和 ACAC 会直接修改端口节点的功率平衡残差，因此端口节点类型需要避免与变流器控制重复约束。
- `result_mode="summary"` 或 `"none"` 会减少结果回填成本，但不适合需要逐设备结果的后处理。
