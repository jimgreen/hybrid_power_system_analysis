# 电网规划 Web 参数维护设计

日期：2026-05-09

## 背景

在现有 `power_plan` 轻量 Web 服务基础上新增“电网规划 Web 网站”的参数维护能力。网站最终包含系统首页、参数维护、启动优化、方案评估、结果比对五个主功能；本设计先聚焦参数维护模块，并为后续优化、评估、比对模块预留数据接口和方案目录结构。

## 目标

- 用原生 HTML/CSS/JavaScript + 现有 Python `http.server` 风格后端实现，不新增前端构建链。
- 每个规划方案保存为一个文件夹，文件夹名就是方案名称。
- 每个方案文件夹内保存一个 `parameters.xlsx` 工作簿，作为参数维护的唯一持久化文件。
- 参数维护界面支持显示、编辑、保存、复制、新建、重命名和删除方案。
- 支持 8760 点风速、太阳辐照、温度、负荷数据的显示和修改。
- 支持多类设备参数表、待选设备数量上下限、设备容量参数的显示和修改。

## 非目标

- 本阶段不实现启动优化算法、方案评估算法和结果比对计算。
- 本阶段不接入数据库。
- 本阶段不实现多人并发编辑锁；保存时采用最后一次保存覆盖当前方案文件。
- 本阶段不实现复杂 Excel 公式、宏、图表或模板美化，只保证数据结构稳定、可读、可编辑。

## 页面与导航

新增 `power_plan/planning.html` 作为电网规划 Web 入口。页面顶部主导航包含：

1. 系统首页
2. 参数维护
3. 启动优化
4. 方案评估
5. 结果比对

当前阶段“参数维护”为可用模块，其余模块显示占位状态，后续按同一方案目录读取输入和输出。

## 参数维护界面布局

页面采用工程软件风格的三栏结构：

- 左侧：方案管理区
  - 方案列表
- 中间：参数编辑区
  - 一级标签：8760时序数据、设备参数、方案概览
  - 8760时序数据页采用上下结构：上方为 8760 点曲线板，下方为小时级数据表。
  - 设备参数页集中展示柴发、风机、光伏、储能PCS、储能电池组、电制氢、储氢罐、燃料电池，全部采用表格方式编辑。
  - 当前方案名称后方集中放置新建方案、复制方案、修改名称、保存方案、删除方案等操作按钮。
- 右侧：校验与摘要区
  - 当前方案名称
  - 8760 行数校验
  - 各设备参数数量统计
  - 数据上下限校验结果

## 参数页面组织

### 8760时序数据页

采用上下结构：

- 上方为 8760 点曲线板，显示风速、太阳辐照、温度、负荷四条全年曲线。
- 下方为小时级数据表，按 12 个月份标签分页显示并编辑小时序号、时间、风速、太阳辐照、温度、负荷；单月数据超出视口时表格区域滚动。

### 设备参数页

柴发、风机、光伏、储能PCS、储能电池组、电制氢、储氢罐、燃料电池全部整合进同一个“设备参数”网页，采用表格方式维护。

页面内按设备类型分成多个表格区块，纵向排列或通过页内锚点快速定位；如果同时显示的设备种类较多，设备表区域独立滚动。设备类型显示按汇总分类勾选：

- 风光柴：柴发、风机、光伏。
- 氢储能：电制氢、储氢罐、燃料电池。
- 电储能：储能PCS、储能电池组。

各设备表字段如下：

- 柴发表格：名称、容量、成本(万元/台)、功率上限(kW)、功率下限(kW)、油耗率(kg/kWh)、数据下限(台)、数据上限(台)。
- 风机表格：名称、容量、成本(万元/台)、切入风速(m/s)、切出风速(m/s)、数据下限(台)、数据上限(台)。
- 光伏表格：名称、容量、成本(万元/台)、发电效率(0-1.0)、数据下限(台)、数据上限(台)。
- 储能PCS表格：名称、功率容量、成本(万元/台)、数据下限(台)、数据上限(台)。
- 储能电池组表格：名称、电池容量、成本(万元/台)、数据下限(台)、数据上限(台)。
- 电制氢表格：名称、功率容量、成本(万元/台)、电-氢效率(Nm3/kWh)、数据下限(台)、数据上限(台)。
- 储氢罐表格：名称、储氢罐容量、成本(万元/台)、数据下限(台)、数据上限(台)。
- 燃料电池表格：名称、功率容量、成本(万元/台)、氢-电效率(kWh/Nm3)、数据下限(台)、数据上限(台)。

每个表格均支持新增行、删除行、单元格编辑。数量上下限默认值为 0。

### 方案概览

此区域作为方案级汇总视图，显示当前方案概况、风速/太阳辐照/温度/负荷的直方图，以及“待选设备列表”。最大值、最小值和平均值跟随直方图卡片展示，不再单独设置时序统计量表格。待选设备列表展示各设备类型、名称、容量、数据下限(台)、数据上限(台)和状态，并提示上限小于下限等错误。概览内容较多时，概览区域独立滚动。

## XLSX 存储结构

根目录：`power_plan/planning_schemes/`

每个方案目录：`power_plan/planning_schemes/<方案名称>/`

每个方案参数文件：`power_plan/planning_schemes/<方案名称>/parameters.xlsx`

工作簿包含以下工作表。

### 8760时序数据

字段：

- `hour_index`：1 到 8760
- `datetime`：可选时间字符串
- `wind_speed`：风速，单位 m/s
- `solar_irradiance`：太阳辐照，单位 W/m2
- `load`：负荷，单位 kW
- `temperature`：温度，单位 ℃

校验：

- 必须正好 8760 行。
- `hour_index` 必须为 1 到 8760 且不可重复。
- 数值字段允许为空但保存时标记警告；优化计算前必须补齐。

### 柴发参数

字段：

- `name`
- `capacity`
- `cost`
- `power_upper`
- `power_lower`
- `fuel_rate`
- `quantity_lower`
- `quantity_upper`

### 风机参数

字段：

- `name`
- `capacity`
- `cost`
- `cut_in_wind_speed`
- `cut_out_wind_speed`
- `quantity_lower`
- `quantity_upper`

### 光伏参数

字段：

- `name`
- `capacity`
- `cost`
- `generation_efficiency`
- `quantity_lower`
- `quantity_upper`

### 储能PCS参数

字段：

- `name`
- `power_capacity`
- `cost`
- `quantity_lower`
- `quantity_upper`

### 储能电池组参数

字段：

- `name`
- `battery_capacity`
- `cost`
- `quantity_lower`
- `quantity_upper`

### 电制氢参数

字段：

- `name`
- `power_capacity`
- `cost`
- `electric_to_hydrogen_efficiency`
- `quantity_lower`
- `quantity_upper`

### 储氢罐参数

字段：

- `name`
- `hydrogen_tank_capacity`
- `cost`
- `quantity_lower`
- `quantity_upper`

### 燃料电池参数

字段：

- `name`
- `power_capacity`
- `cost`
- `hydrogen_to_electric_efficiency`
- `quantity_lower`
- `quantity_upper`

校验：

- 各设备表中的数据下限(台)和数据上限(台)均为数值。
- 同一设备条目的数据上限(台)不得小于数据下限(台)。

## API 设计

所有接口路径以 `/api/planning` 开头。

- `GET /api/planning/schemes`：返回方案列表和当前可读状态。
- `POST /api/planning/schemes`：新建方案，创建文件夹和默认 `parameters.xlsx`。
- `POST /api/planning/schemes/copy`：复制方案文件夹。
- `POST /api/planning/schemes/rename`：重命名方案文件夹。
- `GET /api/planning/schemes/<name>/overview`：读取方案概览和设备参数，不读取 8760 时序明细。
- `GET /api/planning/schemes/<name>/time-series`：按需读取 8760 时序明细。
- `GET /api/planning/schemes/<name>`：读取完整方案参数，保留兼容。
- `PUT /api/planning/schemes/<name>`：保存当前方案参数到 `parameters.xlsx`。
- `DELETE /api/planning/schemes/<name>`：删除方案文件夹。

后端读取 XLSX 后转换为 JSON：

```json
{
  "scheme": "方案A",
  "time_series": [],
  "diesel_generators": [],
  "wind_turbines": [],
  "photovoltaics": [],
  "storage_pcs": [],
  "storage_battery_packs": [],
  "hydrogen_electrolyzers": [],
  "hydrogen_tanks": [],
  "fuel_cells": [],
  "validation": []
}
```

## 依赖

新增 Python 依赖：

- `openpyxl>=3.1.0`

原因：标准库无法读写 `.xlsx`，`openpyxl` 足够轻量，适合当前无数据库、无前端构建链的方案。

## 前端交互

- 页面加载时调用方案列表接口。
- 若不存在方案，显示“新建第一个方案”。
- 选择方案后优先读取 `/overview`，只填充方案概览和设备参数；8760 时序明细在进入时序或概览统计时再按需读取。
- 新建方案、复制方案和修改方案名时，前端先检测方案名称是否已存在，后端仍执行重复名称校验。
- 删除方案前必须弹出确认提示；删除当前方案后按方案列表顺序直接切换到下一个方案，若删除最后一个方案则切换到前一个方案，若无方案则显示未选择状态。
- 8760 时序数据页上方显示风速、太阳辐照、温度、负荷四条全年曲线，支持图例开关。
- 8760 时序数据页下方显示小时级数据表，字段包括小时序号、时间、风速、太阳辐照、温度、负荷。
- 8760 表格按 1 月到 12 月分页显示；修改表格数据后，上方曲线同步刷新。
- 所有表格单元格可直接编辑。
- 设备参数页在同一个网页内用多个表格编辑柴发、风机、光伏、储能PCS、储能电池组、电制氢、储氢罐、燃料电池，支持新增行、删除行、单元格编辑，并可按风光柴、氢储能、电储能三类控制显示。
- 方案概览页显示当前方案概况、风速/太阳辐照/温度/负荷直方图，最大值、最小值、平均值展示在直方图卡片中，并以待选设备列表汇总各设备容量、数据下限(台)和数据上限(台)。
- 保存前执行前端基础校验；后端保存时再执行一次结构校验。
- 保存成功后更新最近保存时间和校验摘要。

## 错误处理

- 方案名为空、包含路径分隔符或非法字符时拒绝创建或重命名。
- 目标方案已存在时拒绝新建、复制或重命名。
- 删除方案时如果用户未确认则不执行；方案不存在或路径非法时后端拒绝删除。
- 读取缺失工作表时返回错误，并提示用户复制默认模板或新建方案。
- 保存失败时不删除旧文件；后端先写入临时文件，成功后替换 `parameters.xlsx`。
- XLSX 行数或字段不完整时返回校验警告，但尽量保留用户数据。

## 测试计划

- 单元测试：方案名校验、默认工作簿创建、XLSX 读写往返、数据上下限校验。
- API 测试：新建方案、复制方案、重命名方案、读取方案、保存方案、删除方案。
- 手工浏览器测试：打开 `planning.html`，完成新建、编辑 8760 数据第一页、编辑设备参数、保存、刷新后数据仍存在。

## 后续扩展

- 方案评估模块读取优化结果并生成指标摘要。
